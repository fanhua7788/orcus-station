# ❄️ ORCUS STATION · 极地科考站失联日志

> 你偶然打开了一台失联极地科考站「奥库斯站」的公用终端。  
> 日志停在最后一分钟，最后一条写着：  
> **「我听见冰下面有人敲门。」**

这是一款网页解谜游戏（ARG），不需要安装任何东西，用浏览器就能玩。

---

## 🎮 开始玩

打开 `index.html`，你就是这台终端前的人了。

- **从主控台的日志开始**，顺着线索一路查下去。
- 全程共 **9 关**，密码被拆成 **5 块档案残片**，散落在各处。
- 残片会在你到达对应页面时**自动记录**，页面顶部的进度条会亮起：`O R C U S`。

> 提示：F12 开发者控制台里，每个页面都留了一句悄悄话。

---

## 🧭 游戏里有哪些地方

| 页面 | 说明 |
|------|------|
| 主控台 | 失联日志，一切的开始 |
| 环境监测 | 气象数据 + 声学记录 |
| 摄像头 | 6 路监控画面 |
| 档案库 | 需要密码的最终入口 |
| 解码工具 | 图像分析终端（见下） |

还有几个页面**不在导航栏里**——需要靠解谜找到它们。

## 🔧 工具与帮助

### 💡 卡住了怎么办
每个关卡页面底部都有一个 **「💡 卡住了？」** 提示框，分三级：
1. **轻微提示** —— 只给方向
2. **明确提示** —— 告诉你关键步骤
3. **直接答案** —— 实在不行就点开

按需点开，不会破坏其他玩家体验。

### 🔬 图像分析终端（解码工具）
在「解码工具」页可以：
- 上传图片，调节**亮度 / 对比度 / Gamma / 色阶**
- 一键「色阶增强」，让暗处藏着的文字显形
- 提取像素**最低比特（LSB）**，自动搜索隐藏签名

### 📊 音频频谱
「环境监测」页的声学记录支持**波形可视化**和**自动解码**——不用听，看波形就能读出摩尔斯码。

### 🧩 残片进度
五块残片 `O / R / C / U / S` 会随进度自动点亮（存在浏览器 localStorage 里）。
想从头再来？在控制台输入 `resetProgress()`。

## 🌐 部署到 GitHub Pages

想把它挂到网上（也可以直接发给朋友玩）：

1. 新建一个 GitHub 仓库，比如叫 `orcus-station`。
2. 把 `arg-orcus` 目录里的**内容**（不是外层文件夹）推上去。
3. 打开仓库 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/ (root)**
   - 点 **Save**
4. 等约 1 分钟，访问 `https://<你的用户名>.github.io/orcus-station/`。

本地预览：直接双击 `index.html`，或在目录里跑 `npx serve .`。

## ⁉️ 常见问题

- **听不到声音？** 浏览器需要用户先点击「播放」，这是浏览器的自动播放策略。
- **图片里的字看不清？** 用解码工具的「一键色阶增强」。
- **卡在密码门？** 五块残片按编号顺序拼，就是密码。
- **进度条不亮？** 进度存在浏览器 localStorage，换浏览器/清缓存会重置。
